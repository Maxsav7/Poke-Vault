# Poke-Vault
An Android application designed to help Pokémon card collectors organize and manage their collections.






- a pokemon card class would need these fields I believe
String name
Double current value (a generic value for a certain print of a card at a certain grade)
Double current value  (specific to each individual card the user owns)
Double purchase price (specific)
int rarity (https://bulbapedia.bulbagarden.net/wiki/Rarity)
short int grade (specific)
String set
short int typing
short int evolution stage
int that tracks all those weird card types (such as V, V max, EX, etc.)
